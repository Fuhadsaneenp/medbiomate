# URL and page migration audit

Existing Medbiomate job and employer slugs remain unchanged. Existing /jobs, /jobs-list, /employers, and /employers-list URLs work. Category, location, and job-type archives retain their original paths rather than replacing the address with a search URL. New jobs/employers use readable title-based slugs generated by the existing backend; older published slugs are retained.

The local sitemap supports /sitemap_index.xml, /sitemap.xml, and original public content sitemap names. Canonicals use https://www.medbiomate.com with one consistent path. Unknown pages return HTTP 404. Imported CMS pages receive their own server-rendered content rather than the homepage. The sitemap merges published local admin edits and excludes drafts.

Checked all 246 imported public page/archive endpoints and representative job/employer detail pages. Compared every content URL against the original public source sitemaps: 15,487 URLs, no missing paths. Four recently published jobs were added to reconcile the snapshot. Data reports: data/route-audit.json and data/original-sitemap-audit.json.

This is URL/content coverage, not complete WordPress feature parity. Commerce shortcodes on /cart, /checkout and /my-account need a replacement commerce implementation if those flows are required. Some legacy account pages use the local candidate dashboard; resume management, messages, meetings, alerts, quiz/calculator plugins, and existing private accounts/applications are not fully migrated. WordPress header/footer/menu template and candidate-profile sitemaps are excluded from the new public sitemap; private candidate information was not imported. Original public content is retained, and no production redirect/DNS changes were made.
